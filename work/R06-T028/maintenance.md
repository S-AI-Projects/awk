## 1. How the Runner Resolves Exercise Files

The Exercism test runner and local CI scripts (specifically `bin/validate_one_exercise` and `bin/validate_exercises`) do **not** search filenames heuristically. Instead, they explicitly parse the `"files"` object in `.meta/config.json`.

In `exercises/practice/say/.meta/config.json`:

```json
{
  "authors": [
    "glennj"
  ],
  "files": {
    "solution": [
      "say.awk"
    ],
    "test": [
      "test-say.bats"
    ],
    "example": [
      ".meta/example.awk"
    ]
  },
  "blurb": "Given a number from 0 to 999,999,999,999, spell out that number in English.",
  "source": "A variation on the JavaRanch CattleDrive, Assignment 4",
  "source_url": "https://web.archive.org/web/20240907035912/https://coderanch.com/wiki/718804"
}
```

### Exact Resolution Steps in `bin/validate_one_exercise`:

1. **Locate Config:**
   Checks for `./.meta/config.json` in the exercise directory.
2. **Resolve Learner Stub:**
   `stub=$(jq -r '.files.solution[0]' "$config")` $\rightarrow$ resolves to `say.awk`.
3. **Resolve Test Suite:**
   `tests=$(jq -r '.files.test[0]' "$config")` $\rightarrow$ resolves to `test-say.bats`.
4. **Resolve Reference Solution:**
   `solution=$(jq -r '.files.example[0] // .files.exemplar[0]' "$config")` $\rightarrow$ resolves to `.meta/example.awk`.
5. **Sandbox Isolation:**
   The runner creates a fresh temporary directory:
   ```bash
   dir=$(mktemp -d)
   cp "${solution}" "${dir}/${stub}"
   cp "${tests}" "${dir}/${tests}"
   cp bats-extra.bash "${dir}"
   cd "${dir}"
   BATS_RUN_SKIPPED=true bats "${tests}"
   ```
   Notice that the reference `.meta/example.awk` is copied into the sandbox as `say.awk` (the declared solution stub name) so that `test-say.bats` tests the reference implementation without touching or modifying the learner's working tree copy of `say.awk`.

## 2. Distinguishing Generated vs. Hand-Maintained Artifacts

| File Path | Type | Origin & Generation Method |
|---|---|---|
| `say.awk` | **Hand-Maintained** | The initial unsolved learner stub authored by track maintainers. |
| `.meta/example.awk` | **Hand-Maintained** | The reference solution written by the track author (`glennj`). |
| `.meta/config.json` | **Hand-Maintained** | Declarative configuration identifying contributors and file mapping. |
| `.meta/template.j2` | **Hand-Maintained** | Jinja2 template defining the structure of generated BATS tests. |
| `test-say.bats` | **Generated** | Auto-generated by `bin/generate_tests` from `.meta/template.j2` and canonical problem specifications. Contains a generated timestamp header. |
| `.meta/tests.toml` | **Generated / Synced** | Auto-generated by `configlet sync --tests` from problem-specifications canonical data UUIDs. |
| `.docs/instructions.md` | **Synced** | Upstream exercise documentation synced from Exercism problem-specifications. |

## 3. Metadata Verification & Boundary Rules

To ensure metadata integrity and prevent security issues (e.g. directory traversal or misplaced files), path resolution enforces four rules:
1. **No Parent Traversal (`..`):** Paths must not contain parent directory segments (`..`).
2. **Relative Paths Only:** Paths must be relative to the exercise root directory.
3. **Internal Confinement:** Every resolved path must strictly reside within `exercises/practice/say/`.
4. **Physical Existence:** Every file declared in `solution`, `test`, `example`, or `editor` must exist on disk.

### Deliberately Invalid Fixture Tests:

The verification script `work/R06-T028/check.py` validates the real configuration and confirms that three deliberately corrupted configurations are rejected with specific errors:

1. **Fixture 1: Missing Reference File**
   - Config: `"example": [".meta/nonexistent-example.awk"]`
   - Outcome: **Rejected** with `FileNotFoundError: Declared file does not exist: '.meta/nonexistent-example.awk'`
2. **Fixture 2: Missing Test File**
   - Config: `"test": ["nonexistent-test.bats"]`
   - Outcome: **Rejected** with `FileNotFoundError: Declared file does not exist: 'nonexistent-test.bats'`
3. **Fixture 3: Parent Traversal / Outside Exercise Path**
   - Config: `"example": ["../outside-exercise.awk"]`
   - Outcome: **Rejected** with `ValueError: Parent traversal detected in declared path: '../outside-exercise.awk'`
